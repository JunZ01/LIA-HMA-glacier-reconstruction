# 全局向量 BP 与原像元几何 v6r1

本版是超过 MATLAB PoLIM 纵剖面功能的模型扩展。新增 P1 平面三角形 × P1 垂向棱柱有限元，联合求解每个三维节点的 u、v。复用 SciPy 稀疏组装与直接线性求解；没有宣称使用已安装的完整冰流框架或与 MATLAB 离散等价。基础物理出处为 Blatter–Pattyn，PoLIM 开发者与论文见项目 NOTICE。

## 应力形式与边界

应变不变量 q = ux² + vy² + ux*vy + (uy+vx)²/4 + uz²/4 + vz²/4。黏度为 0.5 A^(-1/n) (q+regularization)^((1-n)/(2n))。对全域作用量进行 Newton 求解，内部节点共享；弱形式给出内部牵引力平衡，不要求分片线性应力在每条界面逐点相等，也未独立量化界面应力误差。

合成基准：83 像元、332 三角形、201 平面节点、3 垂向节点，即 1206 个速度未知量；冰厚 100 m、冰床沿 y 下降 0.045，A=2.4e-24 Pa^-3 s^-1，n=3。单位为 m、Pa、年，年长 31536000 s。地形跟随坐标中的梯度转换到物理 xyz 坐标。每个棱柱使用三角形 3 点 × 垂向 2 点积分。

基底线性阻力定义为相对水平投影面积的 beta*u，基准 beta=1e4 Pa year/m；侧边/上游端为无滑动，下游端及顶面为自然边界。本次对照仅将 y>850 m 区域的 beta 乘 4，几何与其他参数不变。应变正则化为 1e-20 year^-2，Newton 相对残差阈值 1e-6、最多 60 次，Armijo 回溯。上游响应在 y<550 m 且基准表面速度非零的节点统计，所有垂向层速度差的 L2 范数比为 0.2048023383。

## 原像元几何

使用配套 V3/F19 的正式 positive mask。每个像元中心保留原 B/H，四角为共享该角点的相邻像元均值，各像元切为四个等面积三角形。由此全域面积、体积闭合，局部像元体积会因插值改变。两像元只有角点接触时不共享有限元节点；不加入中心线推定连接，不抬高薄冰，不改变原始源。

系统 2387：88274 像元，178230 平面节点，353096 三角形，一个连通区域，面积 21897469.125 m²、体积 830676873.5593381 m³。逐像元体积改变量绝对值之和 / 源体积 = 0.000522481108；最大单像元变化约 3997.612 m³。最薄源冰约 1.0038e-6 m。这样的静态保存不等于动力学几何已验收。

3 个垂向节点的真实系统有 1069380 个速度未知量。当前 assemble 函数对超过 20000 个未知量明确报错，以防误用原型直接组装耗尽内存；没有悄悄降低分辨率或删掉冰体。完整真实域需要另行开发可扩展求解和薄冰处理，尚未运行真实速度、热力或时间演化。

## 检查与复现

合并 5 项检查通过：物理坐标仿射场应变恒等式；下游阻力改变引起上游响应；水平旋转协变；独立进程 Newton 检查点逐位恢复；真实面积/体积及纯角接触隔离。记录在 runs/v6-global-bp-r1/verification.json。尚未进行网格加密、外部冰流基准或观测速率对照，科学接受状态为 false。

v6 首次导入因缺少括号失败，无数值计算。原源码保留。v6r1 是唯一一次同科学方案的语法技术修正版，失败记录位于 runs/v6-global-bp-v1/failure.json。每次 Newton 迭代原子保存完整速度、迭代信息和合同哈希；运行结束冻结代码归档。开发授权关闭后不允许直接重复运行。
