冰厚、流速与温度的变化

这是人为定义的两条支流和一条主流带，不是系统 2387 的预测。两支流均汇入主流带的第 2 个节点；横轴从各自起点计距。

支流 A 累计汇入约 1,155 m³，支流 B 约 8,034 m³。主流带出口排出约 4,536 m³，因此系统总冰量略有减少；支流之间的交换不会改变总冰量。

已完成的计算链

各支流局部速度求解 → 生成通量 → 汇流处守恒输运 → 更新冰厚 → 垂向热力计算 → 温度反馈流变 → 下一步速度。

合成设定：每条流带 7 个水平节点、5 个垂向节点，初始冰厚分别 65 / 80 / 95 m；表面温度分别 −12 / −6 / −10 ℃，地热通量 0.05 W/m²，表面质量平衡为零。参数仅用于检验计算连接，未读取真实气候数据。
