# BP 边界与垂向分辨率 v8

本版本最高保留 Blatter–Pattyn。已完成结果见 [报告](../reports/bp-boundary-benchmarks-v1/index.html)，冻结计划与证据见项目控制器分支 `polim_lia_v8_bp_boundary_benchmarks_v1`。这轮已终止，不得重复执行已有指纹。

`mechanics.py` 将水平三角形与分段线性垂向节点组合为棱柱，保留两个水平速度分量。`boundary.py` 把严格约束写成 `u = T q + lift`，侧壁不穿透与周期连接均无需罚系数。采用 m、Pa、年；流动因子为 Pa⁻³·年⁻¹，边界给定速度为 m/年，载荷为 Pa，线性摩擦系数为 Pa·年/m。

边界列表必须与 `edge_geometry(mesh)` 返回的外边顺序一一对应：

| kind | 含义 | 附加字段 |
|---|---|---|
| `velocity` | 给定水平速度 | `value` 为可广播至 `(nz,2)` 的数组或 `(xy,sigma,z)` 函数；NaN 分量保留自由 |
| `wall` | 法向速度严格为零 | 可选非负 `friction`，表示切向线性阻力 |
| `pressure_front` | 冰柱压力减外部水压的有效 BP 载荷 | `water_level` 可省略，表示干末端；可选 `water_density` |
| `traction` | 显式给定有效 BP 载荷向量 | `value` 为二分量数组或 `(xy,z,surface,normal)` 函数 |
| `periodic` | 对应位置速度相等 | 顶层 `periodic_pairs` 指定节点配对；标准算例检查对应冰厚一致 |
| `natural` | 零有效 BP 载荷 | 不等于有限冰厚边缘接触空气的物理自由边界 |

底部当前仅支持无滑动；零冰厚节点固定全部速度为零。汇流处是共享节点的内部区域，不添加支流间边界。多边形墙角同时满足相邻边法向条件。

垂向节点数支持 3–33，但整批棱柱装配限制为 100 万个。本轮外部对照使用 3 与 9 个节点。原生真实网格若使用 9 个节点，必须先开发分块装配和相应求解资源计划，不能直接调用当前实现。

合并结果：6/6 求解收敛，5/5 边界积分/约束检查通过，独立断点恢复逐位一致。9 节点解析表面误差 0.78%；公开 BP 的 A/E1 曲线误差 1.03%/7.64%。门槛在运行前冻结。侧壁摩擦及压力前缘目前通过载荷/约束检查，仍需独立非线性受载边界算例；真实边界分类和真实动力学适用性未完成。

独立参考数据在 `reference/ismip-hom-2008`：原始归档、所选原始文件、转换脚本、转换曲线和来源哈希均保留。E000 为无滑动 E1，E001 不属于本轮参考。新的数值运行需遵循根目录项目事实与执行合同，另行登记版本；不得重跑已完成成员。
