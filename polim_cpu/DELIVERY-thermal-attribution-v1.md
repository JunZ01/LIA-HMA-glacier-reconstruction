# 第三版热力反馈对照交付

已完成系统 2387 的一次固定流动参数对照，推进 0.1 年、22 步，保存 23 个完整断点。原来的热力试算直接复用，未重复计算；两组使用相同的 4094 格初始剖面、气候、初始冰温、求解代码和运行环境。

| 指标 | 温度反馈试算 | 固定 A 对照 |
|---|---:|---:|
| 初始最大流速（m/年） | 9367.1 | 7131.0 |
| 最终最大流速（m/年） | 13425.7 | 3905.2 |
| 时间步 / 断点 | 52 / 53 | 22 / 23 |
| 最大累计质量误差（m³） | 2.02×10⁻⁷ | 2.76×10⁻⁷ |

初始状态一致时，温度与含水率流变映射使最大流速提高约 31.4%。最终速度比为 3.44，包含了两条轨迹各自的冰厚、热状态与融化演化，不能解释为纯温度的直接贡献；最大值也可能来自不同位置。

原实现将来源的标量 A 锚定在压力修正后的 −10°C，再叠加软化；来源一维模型直接使用标量 A。这一映射属于实验假设，尚未完成跨模型等价校准。固定 A 对照仍出现较高速度，因此尚不能确认原始陡坡、继承参数和动量模型分别贡献多少，也没有据此更改默认物理设置或声称科学验收。

继续采用用户确认的气候冰温初始化和 0.05 W/m² 地热通量。固定 A 对照仍计算温度、含水率、应变热和底部融化。所有 76 个断点通过合并完整性检查；复用已通过的 7 项工程检查。研究分支已完成并关闭，主线及接受数 58/191 保持不变。
