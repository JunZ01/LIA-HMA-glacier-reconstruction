# 支流局部速度与热力耦合 v5

完成一个可连续推进和恢复的合成计算链：v3 各支流局部 BP 速度 → v4 图冰量/焓输运 → 冰厚更新 → v3 垂向热力 → 流变与速度反馈。v3/v4 冻结代码未修改；本次实现与依赖哈希全部登记。

## 接口与离散假设

`coupled.fixture()` 返回显式合成状态、汇流关系和参数。`diagnose_all(states, parameters)` 计算初始速度、垂向运动和热力诊断；`advance_coupled(states, junctions, parameters, requested_dt)` 返回新状态及诊断，输入状态不变。汇流元组为 `(child_branch, parent_branch, receiving_node)`。

节点状态包含 x、bed、h、width、cell_width（m），E（J/kg），surface_c（℃），smb/melt（m ice/year），u/w（m/year）等；完整检查点保存全部状态和同步历史。CPU float64，单线程。时间步按所有边的总出流占供给节点冰量比例限制为不超过 0.4，并不超过请求步长。

各支流内部通量沿用 v3；支流末端通量由末端平均速度 × 供给侧冰厚 × 支流口宽度产生。主流带末端是开放出口；禁止未提供外部状态的逆向入口。各汇流关系必须无环且每条支流仅有一个下游。

**局部动量近似**：速度在各条流带独立求解。源头采用原 v3 headwall 条件，末端自然应力条件；汇流不共享速度自由度，没有转弯应力或应力连续性求解。当前代码不是全局网络 BP 模型。

**热力分裂近似**：先根据步首速度推进水平输运，再以该步速度和应变热推进垂向热力，最后重新求解速度。基底融化进入下一步质量损失。水平输运采用与垂向节点一致的梯形质量权重；混合同一相对层，无垂向重映射。水平平流在垂向模块内关闭，避免重复计算。垂向能量改变量、排水量和薄冰交换单独记录，未声称完整热力能量预算已闭合。
