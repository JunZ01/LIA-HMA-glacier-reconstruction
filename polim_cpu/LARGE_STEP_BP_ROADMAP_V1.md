# BP 大步长积分开发规划 v1

日期：2026-09-17。状态：规划已建立，尚未授权或启动本规划中的新模拟。

## 目标与当前基础

目标是减少千年模拟所需的时间推进次数及 BP 总求解次数。保留主流、支流和汇流区的 BP 应力传递，开发可采用季度、半年乃至一年步长的冰厚—速度耦合积分。年度是最大候选步长，不预先承诺任何冰川全年都能一步完成。

当前有两套需要明确区分的实现：

- 百年历史入口仍为 `gpu_model_v5.py` / `historical_worker_v5.py`，已完成系统2387的1470—1570年历史气候试算。
- 加速候选为 `adaptive_bp_worker_v4.py`、`adaptive_bp_solve_v1.py`、`projected_amg_v1.py`、`packed_storage_v1.py`。两个一年窗口的推进耗时分别由74.498秒降至41.122秒、由39.142秒降至12.236秒，尚未替换百年入口。

上述加速主要减少线性迭代和检查点写入；牛顿迭代次数没有显著减少。先前允许短期沿用速度的试验未跳过任何求解，不继续把它当作已实现的加速收益。

本规划中的精度阈值是拟定的工程对照标准，不是古冰面观测误差或科学接受标准。正式启动前，需冻结实际代码、输入、参数、数值阈值和任务指纹，并登记新的运行分支；本规划文件不能直接用于启动。

## 保留的物理和数据约定

- 首个对象为系统2387，50米网格；先解决时间积分，不同时修改网格和物理参数。
- 使用 BP、双精度、固定床面、固定材料参数和无滑动边界。保持当前有限计算范围及向外输出处理。
- 使用现有逐年历史温度、月度降水基线和温度指数物质平衡参数；降水异常仍关闭。
- 月度气候仍用于计算年度净物质平衡。每个气候年开始时，用该年的初始冰面刷新一次物质平衡，与现有历史算法一致。试验步不得跨越气候年边界。
- BP 完整求解的相对残差仍为1e-6；不通过放松 BP 精度获得表面加速。
- 扩散近似只用于初值预测、预条件或收敛后消失的稳定化。最终需要满足离散后的原 BP 与质量守恒耦合方程，不增加永久的人工扩散或直接平滑古冰面。
- 主线191系统、接受计数及其他运行任务不变。

## 最小算法

当前动力学是一个连续的控制方程系统。大步长收益来自改变数值积分与耦合求解方式，而不是仅把冰面写成连续函数。

一个候选大步从已接受状态 H_old 开始：

1. 使用局部扩散近似产生新冰厚初值。沿用原床面、网格和边界，不把该预测当作最终物理解。
2. 在候选冰厚上求解 BP，得到深度平均速度及边通量。
3. 用隐式守恒输运更新冰厚。优先实现固定速度下的隐式迎风有限体积离散，再通过外层迭代处理速度对新冰面的依赖。
4. 交替校正冰厚和 BP，必要时对外层更新做阻尼。验证候选状态的质量方程残差及 BP 残差，而不仅比较相邻两次迭代的变化量。
5. 收敛后接受该步；若超出工作预算、非负约束处理失败或误差控制失败，从原已接受状态缩小时间步，不累计被拒绝尝试的积累、消融和边界输出。

拟采用的后向欧拉关系为：

`(H_new - H_old) / dt = m_actual - div(H_new * mean_u_BP[H_new])`

这只是时间离散的定义，不意味着固定速度下的输运稳定性可以自动保证整个 BP—几何耦合的稳定和精度。

### 约束与求解器

- H必须非负；内部公共边采用同一个通量值，使相邻控制体的流出、流入严格抵消。
- 消融受可用冰量约束，允许同期冰流补给。实际施加的物质平衡需进入体积账本，不能先扣全年消融、再处理全年输运。
- 非负约束优先采用活动集/互补条件。若引入消融不足乘子，只能抵消无法实现的负物质平衡，不能补偿任意输运误差；所有修正单独记录。
- 不允许把负冰厚简单裁成零而不核算其质量效应。
- BP采用当前活动节点投影的AMG；无冰节点的速度修正保持零。
- 隐式迎风输运矩阵通常不对称，不能直接照搬BP的PCG。实现时选择适用的稀疏直接法或GMRES/BiCGSTAB，并按实际开销决定CPU或GPU路径。扩散预测若为对称正定系统，可使用PCG。
- 首版采用阻尼外层迭代，不同时引入新的神经网络、复杂代理模型或另一套冰川物理。

## 分阶段交付

| 阶段 | 要做的工作 | 交付与进入下一阶段的条件 |
|---|---|---|
| 1. 最小可运行积分器 | 接入已通过的加速模块；实现隐式冰厚更新、非负和守恒处理；定义耦合残差；实现扩散预测开关 | 可从既有检查点运行一个大步；现有30天模式仍可读取旧结果；未开始长跑 |
| 2. 一轮集中对比 | 在1482—1484和1552—1554两个窗口，比较最大步长1/4年、1/2年、1年；读取既有30天历史轨迹作参考 | 统一检查精度、守恒、总耗时、BP次数和失败回退；选择合格且最快的方案，允许结论为半年或季度 |
| 3. 连续运行与入口整合 | 先将选定方案用于一个20年窗口，再通过已登记的连续性检查进入100年范围；阶段及输出根在启动前冻结 | 连续状态和年度账本完整，年度检查点可恢复，时间误差无持续漂移，总耗时收益保留；再登记为可选运行后端 |
| 4. 重建方法闭环 | 将稳定的前向模型用于少量重建参数的约束反演；扩散预测提供快速初值，最终BP校正 | 完成单冰川“地貌约束—几何重建—动力学调整”闭环；独立验证与OGGM对照随后进行 |

阶段2采用两个不同动力学状态的窗口，避免层层叠加短预试。阶段3的20年窗口建议1510—1530，100年范围仍为1470—1570；新算法结果与已有基准比较，不重跑已完成的基准模型。

1000年运行属于后续扩展。当前实际历史资料不足以直接覆盖任意1000年，必须先明确可用气候时段或另立平衡调整实验。不能为获得千年计时而暗中重复、外推或更改历史气候。短窗口外推耗时与真实千年耗时分开报告。

## 合并验证与拟定验收标准

验证分为一次组合技术检查、一轮科学对照和选定方案的连续运行，避免反复增加预试。

### 组合技术检查

与首次运行放在同一个驱动内：检查隐式离散的守恒和非负、原始BP算子一致性、恢复后年度物质平衡缓存一致性、检查点跨进程恢复，以及进度文件暂不可写时继续计算。保留成功推进，避免重算预试前缀。

### 每个接受的大步

- 所有数组有限，冰厚非负；原BP相对残差≤1e-6。
- 相对体积账本误差≤1e-10，账本包含实际源项和边界输出。
- 归一化局部厚度方程残差≤1e-8。分母明确使用该步初始总冰量及源项、总通量尺度，不能只用全域净残差，因为局部正负误差可能抵消。
- 记录外层迭代、BP调用、牛顿及CG迭代、拒绝步、回退、计算/构建/写盘耗时。
- 拟定外层预算8次完整BP校正；超出则回退，不无限迭代。该数值是工作预算，不是收敛判据，正式运行前冻结。

### 对照现有30天轨迹

在每个年度终点比较，以下是拟定工程门槛：

| 指标 | 拟定门槛 |
|---|---:|
| 冰体积相对差异 | ≤0.5% |
| 按控制体面积加权的冰厚RMS差异 | ≤0.2米 |
| 最大局部冰厚差异 | ≤2米 |
| 按面积加权的表面速度相对L2差异 | ≤2% |
| 窗口累计边界输出差异 | ≤参考输出绝对值的1%或窗口初始体积的1e-5，两者取大 |

同时保存冰缘、汇流区和原高速区差异图。空间掩膜从已有几何和既有诊断中冻结，不按试验结果挑选有利区域。30天轨迹是数值参考，不是观测真值。若参考自身不足以判定时间误差，应针对具体差异提出一次有依据的检查，而非默认重跑整条参考轨迹。

首轮季度/半年/年度对比用于校准后续步长选择，不默认在每个生产步做“一整步与两个半步”三套完整BP。首版先采用通过检验的步长上限、年界限幅和失败时减半；自动增步规则须依据对比结果另行冻结。非线性收敛不能替代时间精度检验。

### 性能判断

- 加速目标：在已通过的v35求解和年度存储基础上，争取进一步降低总耗时至少2倍。这是开发目标，不是预先保证。
- 先满足精度门槛，再选择实测总耗时最小的方案；年度步若更慢，选半年或季度。
- 必须计入预测、BP校正、预条件器构建、被拒绝的尝试、输运、写盘和恢复开销；初始化单独报告。
- 同时给出相对原v32历史记录和相对v35执行方式的收益。现有v35仅有两个一年窗口，不能当作所有新窗口的直接计时基准；若需要严格同窗口计时，必须先登记唯一的匹配控制试验。不得把单个窗口外推描述为真实千年实测。

## 持久化、停止与工作边界

采用年度耐久检查点，包含H、u、精确年份、年度气候源与缓存哈希、累计实际物质平衡和边界输出、步长控制状态、逐步统计。中断后从最后一个已封存年度恢复，最多重算未保存的一年；已保存年份和已完成组合不重算。

运行前读取项目事实、执行契约和当前状态并通过控制器验证。每个运行配置应有独立的代码/输入哈希、数值门槛、范围、预算和输出目录。研究分支不会改变OGGM主线、191系统计数或科学接受状态。

算法无法同时满足误差与性能要求时，保留当前30天加速候选并关闭该积分方案，不临时放宽门槛。已识别的实现故障按执行契约登记一次技术修复；不得把同一种失败不断换名重跑。

本次用户授权的是建立规划。下一项实际工作是阶段1的隐式守恒输运与BP耦合原型；本次不启动模拟，也不修改主入口或工作默认设置。
