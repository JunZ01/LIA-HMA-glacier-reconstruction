## 输运接口

`advance(volume, enthalpy, edges, flux, dt, *, layer_weights=None, addition=None, addition_enthalpy=None, removal=None)` 返回新冰量、新比焓和收支诊断。

- `volume`：节点冰量，m³，形状 `(N,)`。
- `enthalpy`：比焓，J/kg，形状 `(N,L)`。密度固定 900 kg/m³。
- `edges`：整数节点对 `(M,2)`；第二端点为 -1 表示外部出口。
- `flux`：m³/year；正值沿边方向，负值反向。外部出口不允许负通量，外部流入须显式传入来源冰量和焓。
- `dt`：年；`addition` 和 `removal` 是整个步长内的 m³，不是速率。正补给必须提供 `addition_enthalpy`。
- `layer_weights`：共同的正层质量比例，总和 1；默认各层等比例。

所有边同时读取步首状态，先按供给节点的总可用冰量限制出流，再汇入接收节点。一步内新流入的冰量不能继续供给出流。外部补给与限量消融在输运后应用。各层按同一比例输送，未实现垂向坐标重映射、导热或相变。焓守恒不能替代完整热力学验证。
