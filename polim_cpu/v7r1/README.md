# 真实原生网格上的全域 BP 诊断

系统 2387 的首次固定几何联合速度诊断。原生网格取自已冻结的 v6r1：178,230 个平面节点、353,096 个三角形，88,274 个正式正冰厚像元。每个平面节点有 3 个垂向节点，各求解 u、v；底部严格无滑动后保留 712,920 个自由未知量。没有修改冰厚、增加连接段或水平粗化。

## 方程与求解

沿用 v6r1 的物理坐标 P1 三角形 × P1 垂向弱形式，以及每三角形每垂向单元 3 × 2 个积分点。基底速度消元后，每个平面三角形将两个垂向单元累加成 12 × 12 局部矩阵，避免存储每个积分点的完整矩阵。Numba 8 线程组装，SciPy 稀疏矩阵，PyAMG 5.2.1 对称平滑聚合与 CG。PyAMG 位于项目 `.runtime/pyamg-5.2.1`，不改全局环境。

Glen n = 3；A = 7.538801981725612e-23 Pa^-3 s^-1，转换到年制后使用。沿用项目参数属于模型间移用，未在这个空间几何上重新标定。底部无滑动 fs = 0；表面及整个阶梯侧边界采用自然有效 BP 应力边界，包括仍有非零厚度的外边界。没有额外限制侧向流动。仅诊断速度和应力，不推进冰厚，不读气候，不反馈温度。

应变不变量为 ux² + vy² + ux·vy + (uy+vx)²/4 + uz²/4 + vz²/4。应力取三角形重心和 sigma = 0.25、0.75 处的物理梯度，不做节点应力平滑。共享速度节点与整体弱形式提供内部受力联系；逐面应力通量误差未独立评估。

## 数值精度修复

初版 `v7` 的真实计算在 80 轮上限停止，残差 3.56858e-6，未达到冻结阈值 1e-6。其总能量约 -3.39227e16，末段能量变化不足以可靠判定步长，残差反复；失败文件和全部迭代保留在 `../runs/v7-native-global-bp-v1`。

唯一技术修正版 `v7r1` 保持物理、几何、积分与最终阈值不变。当预期 Armijo 能量下降小于 64 倍机器精度乘总能量尺度时，改用相对残差下降接受步长。同时要求缩放前线性残差不超过当前残差的 0.1；最多 5 次收紧 CG 容差，总计不超过 500 次 CG 迭代。新合同、新指纹，从相同 SIA 初值重算，不冒充旧合同的断点续算。

每轮保存带哈希封印的自由速度状态。在合成算例上，独立进程从第 1 轮恢复，最终速度逐位相同。每次重建 AMG 使用同一随机种子。真实场景仅保存了恢复所需状态；没有另外进行整场独立复算。

## 输出与解释边界

`../runs/v7-native-global-bp-r1/fields.npz`：完整三层速度（m/年）及两个垂向单元中心的应力。`result.json` 给出列名、单位、残差、速度统计和计算设定。`../reports/native-global-bp-v1` 显示冰厚、速度方向和汇流应力，并保留色标定义及完整未截断数组。

极高速区与非常陡的重建冰面同时出现。其因果贡献尚未分离；需要先核查源动力学几何，再分析常数 A 移用、侧边界及垂向分辨率。数值收敛不能替代这些科学判断。本分支不改变主线通过数量，不能直接接入真实演化或宣称观测吻合。

原 MATLAB PoLIM 是纵剖面模型；这里的三维向量离散为新增扩展。原项目 NOTICE、LICENSE 和引用保持有效：Wang et al. (2020), https://doi.org/10.1016/j.cageo.2020.104526。
