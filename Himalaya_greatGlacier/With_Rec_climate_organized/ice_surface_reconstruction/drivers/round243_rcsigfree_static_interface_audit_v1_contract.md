# Round 243 contract: RCSigFree static interface audit

## Purpose

Recover any statically visible input, output, menu, option, chronology, spline,
power-transform, and signal-free interface clues before deciding how to execute
the official RCSigFree binary.

## Frozen actions

- Verify the executable and bundled Melvin (2008) PDF hashes from Round 195.
- Read PE header metadata without loading or executing the binary.
- Extract ASCII and UTF-16LE printable strings of at least four characters.
- Save a complete string inventory and a keyword-filtered interface inventory.
- Extract the bundled method-paper text page by page.
- Do not infer unsupported command-line behavior from strings alone.

The executable is never loaded or run. Original files are read-only. No tree
ring, climate, locked-period, Jionglacuo, EnKF, production reconstruction,
correction, or OGGM value is accessed.
