# Round 202 Zhu 2011 exact ResearchGate download

Attempt the single indexed `Zhuetal2011P3.xls` download endpoint exposed by the
ResearchGate publication page. Save the response in an independent directory,
identify only its HTTP metadata and binary signature, and hash it if it is a
spreadsheet.

Do not open any spreadsheet cell, parse any year or value, access 1921-1939 or
Jionglacuo, or run PSM, reconstruction, correction, EnKF, MATLAB, or OGGM.
HTML, login, challenge, and error responses are retained as failed access
evidence and are never renamed as data.
