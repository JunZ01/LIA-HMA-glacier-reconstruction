# Round 147 HMA Temperature Public Acquisition V1

## Objective

Acquire genuinely new, machine-readable HMA temperature proxy evidence before any further reconstruction-method experiment.

## Priority targets

1. Upper Indus/northern Pakistan `Pinus wallichiana` MXD associated with DOI `10.1016/j.scitotenv.2024.177393`.
2. Hongyuan/eastern QTP `Picea purpurea` blue-intensity chronology associated with DOI `10.1016/j.gloplacha.2024.104381`.
3. Related eastern-QTP earlywood blue-intensity data associated with DOI `10.1016/j.palaeo.2025.113220`, subject to shared-material identity closure.
4. Other independently archived HMA temperature records meeting the same rules.

## Acquisition gates

- The numeric file must be downloadable without account registration or circumvention.
- It must contain an annual proxy chronology or temperature reconstruction, not only a plotted figure, image, or descriptive table.
- Metadata must identify the archive/measurement, location or domain, climate variable, target season, coverage, source paper, and license/access terms.
- Preferred coverage begins no later than 1500 and extends through at least 2000; it must contain enough 1940-2000 overlap for frozen modern validation.
- Every downloaded file enters a new `raw_unopened` directory with URL, HTTP metadata, size, SHA256, and retrieval time recorded before any value parsing.
- A candidate is not admitted merely because it is downloadable. It must later pass boundary-safe release, exact identity/sequence closure against proxy6/proxy9 and all newly acquired candidates, and a preregistered Berkeley/CRU modern OOF test.

## Boundaries

- Do not register accounts, submit author-contact forms, use credentials, bypass access controls, or scrape values from figures.
- Do not decode or use 1921-1939 values during acquisition or preflight.
- Existing sealed validation records, including Jionglacuo, remain unopened.
- No EnKF, production reconstruction, OGGM run, or climate-parameter tuning is authorized by acquisition alone.
