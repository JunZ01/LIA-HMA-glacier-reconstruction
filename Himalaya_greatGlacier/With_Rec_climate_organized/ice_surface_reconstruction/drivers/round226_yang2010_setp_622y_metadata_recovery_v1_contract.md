This round may identify filenames, file signatures, hashes, coordinates,
species, sample counts, chronology bounds, calibration target, and nearest
project proxy groups. It must not extract PDF text, inspect figures, digitize a
trajectory, read proxy or reconstructed annual values, access any 1921-1939
numeric value, access Jionglacuo, run a PSM or reconstruction, modify production

present and source independence can be established. A PDF-only deposit or an
unresolved relationship to an existing project sequence remains metadata-only
