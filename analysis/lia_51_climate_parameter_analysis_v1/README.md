# 51条LIA冰川：气候参数联合分析

打开 `index.html` 查看8幅分析图、统一51条参数清单、参数分组历史曲线及联合条件检验。历史最大值到2000年的长度/体积损失、峰值时间与固定1900—2000阶段并列展示，避免只考察近现代退缩。

51条是本版本统一主样本。41条采用恒定历史附加温度校正，10条采用时变校正；原32/19身份保留在数据来源字段，不修改项目正式接受名单。

原19条只在旧报告中列出搜索倍率。本版本通过冻结基础参数表、使用该输入的批次计划和代表结果，恢复实际融化因子、降水因子、冰流参数与基础温度偏差。保留倍率和来源证据，原报告不覆盖。

主要文件：

- `parameters_51.json`：51条完整实际参数及地形、历史响应、来源字段。
- `temperature_policies.json`：注册策略的年整点q(t)和基础偏差+q(t)，不是重建温度或原始气候序列。
- `parameter_summary.json`、`parameter_correlations.json`：全样本与分支分布、参数相关。
- `associations.json`：全部单参数—历史响应相关，含不可计算项。
- `adjusted_associations.json`：地形/分支控制与联合气候参数控制的条件秩相关。
- `robustness.json`：等气候像元中位数及逐像元剔除检查。
- `group_statistics.json`：按q均值、融化因子、降水因子三分位分组的L/V曲线统计。
- `source_manifest.json`、`output_manifest.json`、`validation.json`：输入/输出哈希及独立检查。

统计为探索性描述，无显著性筛选，不提供因果效应或总体置信区间。参数经过既有拟合和曲线选择，存在选择偏差；同一模型分支内的参数相关也不能证明气候归因。10条时变校正与合成模型分支重合，无法由跨组比较独立识别时变校正作用。

输入、参数、模型和曲线均未修改；没有读取原始气候数组，没有启动模拟或新的参数搜索。

重建前遵守项目AGENTS与权威文件阅读要求，再运行 `build_report.py` 和 `validate_report.py`。验证器使用秩相关矩阵逆矩阵公式独立核验构建器的残差相关计算。
