统一51条主样本｜41条恒定校正 + 10条时变校正｜只分析已保存历史结果

本报告研究参数配置与历史响应之间的关系，不把拟合温度校正当作古温度重建，也不把相关当作独立气候归因。

2. 气候输入与校正不是同一个量

共同框架为GSWP3_W5E5的1961—1990年月气候态，加ensemble_rec_ref重建温度距平；降水异常关闭，再由各冰川降水因子缩放。温度校正示意包含基础偏差与历史q(t)，不包含实际重建距平或高程递减率项。恒定q不代表恒定历史气候；spinup校正只描述初态构建，不解释成真实古温度。

这51条包含41条恒定q和10条时变q。时变策略与合成系统模型分支重合，因此不能从组间差别分离出“时变校正的独立作用”。具体年整点策略见 校正策略数据。本次没有读取原始气候数组或重新运行模型。

3. 参数组合：先看是否相互关联

完整矩阵同时包含基础温度偏差、历史校正、融化因子、降水因子、冰流参数以及地形变量。基础偏差与平均q相加得到组合偏差，这是定义上的联系，不能当作独立证据。其他相关也可能来自空间分布、校准策略或择优过程，不能仅凭矩阵认定参数补偿机制。

4. 参数与历史变化

主响应为1900—2000年的相对体积损失，正值表示损失。所有51条进入主分析；峰值至2000年的长度/体积损失、窗口内部峰值年份作为补充。边界峰值不作为明确最大期参与峰值时间相关。

全部参数—响应相关同时保存弱相关、不可计算项和样本数，不按显著性筛选。

4b. 从历史最大值到2000：不只看20世纪

并列检查1500—2000窗口内最大长度、最大体积到2000年的损失，以及峰值出现时间。固定1900—2000阶段便于比较同一时间段；最大值到2000则反映各冰川各自峰值后的变化，两者回答不同问题。最大值来自模型曲线，不等于独立定年的LIA最大期。

5. 联合条件与删除稳健性

联合检验控制其余三项气候参数、末端高程、高程—面积分布、经度、面积、模型分支及冰流参数。结果为秩残差之间的相关，而不是每升温1℃的损失效应。统一51条与恒定41条并列；逐登记气候像元剔除用于检查单个共享气候区域的影响，范围不是置信区间。

值得优先关注的是：融化因子的原始相关为 0.37，联合控制后为 0.19；平均q的原始相关为 -0.06，不能据此把附加校正大小当作退缩幅度的单一解释。基础温度偏差由正相关转为负的条件相关，提示原始关系依赖于样本和协变量构成；这不是‘升温减缓退缩’的证据。

共有 37 条基础温度偏差恰为0，其余为非零校准值，不能把这组参数简单看作均匀连续的气候观测。10条时变策略在1900—2000年增加的q最多约 0.057 ℃，与其1470—2000总增量不同；这里比较的是附加校正，不是这一时期真实变暖量。

参数是在现有拟合/选择流程后得到的。样本量有限、共享气候像元及校准目标约束仍会影响解释；条件控制并不构成独立气候归因。10条时变样本只报告描述性相关，不强行拟合多参数控制模型。

6. 空间差异

将实际参数放回冰川系统位置，判断参数大小是否随空间位置共同变化。51条对应33个登记气候像元；地图上的点不代表区域连续气候场。
