# 51条冰川：演变时段差异与地形、气候参数

在前一版阶段与可靠性图谱上继续分析。51条仍为统一样本，不重新筛选、
不启动模拟、不读取原始气候数组，不改变正式接纳记录。

使用固定世纪区间作为比较工具，不将其称为已经独立定年的LIA阶段。
主指标是19世纪与17世纪的平均长度/体积差异，占同一历史窗口最大值的百分比；
辅以近最大范围持续比例，避免把所有曲线压缩成一个峰值年。

方法与敏感性规则在 `methods.json` 中先行明确。本次属于基于既有图谱的探索分析，
不能把内部相关或跨像元预测表现称为独立机制验证。

`index.html` 为阅读入口；所有图表数据、来源哈希和验证记录均保留在本目录。
