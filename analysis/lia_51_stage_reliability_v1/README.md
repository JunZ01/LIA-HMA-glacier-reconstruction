# 51条冰川：LIA演变阶段与可靠性图谱

仅后处理已经保存的历史长度、面积、体积；51条作为统一分析样本。
不启动模拟，不重新择优，不修改正式接纳台账，不打开原始气候数组。

方法先在 `methods.json` 中明确，再计算结果。1%近最大范围、30年时序差异、
2个百分点幅度差异都是本次描述性诊断规则，配套敏感性分析；不是原有科学接纳门槛，
也不是已验证的年代误差。

`index.html` 为中文阅读入口；`atlas.json` 为51条完整诊断；
`case_diagnostics.json` 和 `conditional_reliability.json` 保留已有备选方案的条件性比较；
`regional_activity.json` 为样本内推进—退缩与近最大范围占比；
`validation.json`、`source_manifest.json` 和 `output_manifest.json` 提供核查记录。

各冰川均有独立图页链接，不将并列峰值或不连续近最大时段连成一个连续最大期。
源数据若仅每10年保存，任何年度插值都不提升其时间精度。
