选择规则在计算配对曲线差异前固定，未按结果强弱挑选。但这是已知全样本关联后的探索，不是独立确认。所有27组仍完整保留。

2622 → 2827：坡度相近、面积比≤2中，高程差最大

长度持续差异：1700—1710；持续约196年；延伸至1900边界；体积持续差异：1710—1720；持续约183年；延伸至1900边界。这里只报告1700—1900窗口内首次达到2个百分点、30年条件的位置，不称为历史分化的真实起点。

高程相差1277m、坡度仅差0.65°。18世纪起相对演变明显分离，36种定义均检测到长度和体积持续差异，首次区间总体为1700—1740。但基础温偏差4.04℃、附加q差1.38℃、冰流参数比2.13，且无已审查备选曲线，不能把分离单独归因于末端高程。

1012 → 1044：高程差≤600m、面积比≤2中，坡度差最大

长度持续差异：未达到本次标准；体积持续差异：未达到本次标准。这里只报告1700—1900窗口内首次达到2个百分点、30年条件的位置，不称为历史分化的真实起点。

这是重要的对照结果：坡度相差4.73°，但1700年之后两条归一化曲线很接近，长度与体积均未达到主持续差异标准。较大的长度差异主要在1500—1600出现；其早期差异还受1012已有备选影响。融化因子相差约1.77倍，不能据此认定坡度无作用。

2939 → 2928：有明显地形差异的其余配对中，参数距离最小

长度持续差异：1840—1850；持续约48年；体积持续差异：未达到本次标准。这里只报告1700—1900窗口内首次达到2个百分点、30年条件的位置，不称为历史分化的真实起点。

参数距离在预设候选中最小，不代表参数相同：融化因子比仍为1.54。长度差异反复变号，主标准仅在约1840—1850进入持续正差异，约1890—1900退出；变更参考期或阈值后，首次区间可落在1700—1860，方向也会改变。体积未达到主标准，不能用一个分化年份概括两项指标。

  • 早期与现代背景完整展示，但无1470年前推断；1500年不代表初值影响已消失，1900年不是独立定年的LIA终点。

  • 参数距离采用全51条的四分位距缩放；基础温偏四分位距为零但并非常数，改用标准差，未将其忽略。此技术修正未改变三个重点配对。
