# LIA 51条冰川系统分析 v1

打开 `index.html` 查看七个分析模块、8幅总览图与51条可展开的历史曲线。

研究对象是保存的1470—2000年历史模拟，主展示窗口1500—2000年。spinup仅作初态交接核查。32条已认可冰川是主样本，19条候选是补充样本；代表曲线沿用已有选择，不重新评分、不提升候选身份。

## 交付内容

- 一致性：源文件哈希、初态标量交接、历史曲线闭合、LIA和现代长度目标残差。
- 历史：L/A/V曲线、原生时间步峰值与并列年份、边界标记、阶段净变化率、持续下降分箱诊断。
- 空间：位置、末端坐标、空间差异及峰值时间分布；经度带不作气候区解释。
- 地形：末端高程、面积、长度、坡度、高差、厚度、高程—面积分布、流线方向与变化的描述性关系。
- 参数：恒定/时变校正、物理参数与搜索倍率区分、15条旧候选保存组合的条件性范围。
- 稳健性：样本身份、模型路线、窗口、原生取样、基准年、分组阈值、气候像元与删除敏感性；明确独立观测证据缺口。
- 综合量：固定样本的同步总体积/面积与单条贡献，不外推191条或喜马拉雅总体。

## 输出文件

`features.json` 为51条统一属性表；`diagnostics.json` 为历史阶段诊断；`parameters.json` 为参数来源表；`source_audit.json` 为逐条交接核查。

`group_statistics.json` 保存分组L/A/V的绝对值和相对模拟2000年的中位数与四分位数；`aggregate.json` 保存同步总量和损失贡献。

`associations.json`、`robustness.json`、`saved_alternative_sensitivity.json` 提供完整描述性检验结果，而非只提供强相关项。

`validation.json` 是独立算术/来源/覆盖检查；`source_manifest.json` 与 `output_manifest.json` 分别保存输入和输出哈希。

## 解释边界

LIA登记1400年不是独立定年的最大期；1470以前的演变不能由这些曲线重建。混合年度和十年输出的汇总峰值年不具有年度定年精度。静态V3几何与动力初态体积之差不是历史损失。长度匹配与数值复现都不能自动验证体积历史。

气候像元采用已有登记，不重新读取原始气候数据。校正策略图为年整点示意，不等于完整有效气候强迫。相关、条件秩相关及已保存参数范围均不构成因果归因或区域总体置信区间。

当前证据尚未建立独立定年、历史末端或同空间范围体积观测的联合验证。报告把该缺口明确列出，没有将其伪装为已完成验证。

## 重建

须先遵守项目AGENTS及三份权威文件的阅读要求。使用现有 `oggm_env2` Python 运行本目录的 `build_report.py`，随后运行 `validate_report.py`。构建器再次运行只读控制器验证，只写本目录，不启动OGGM动力模拟。
